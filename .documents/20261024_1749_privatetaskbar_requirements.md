# PrivateTaskbar 定制任务栏插件 — 需求规格（终版）

> 本文是 grilling 需求访谈（2026-10-24，三轮）的固化结论，**与实施计划冲突时以本文为准**。
> 实施计划：`.documents/20261024_1644_privatetaskbar.md`（提供架构与参考实现）。

## 1. 定位与形态

- NPS 插件（类库工程，目录 `PrivateTaskbar/`），不改宿主任何代码。
- 插件身份：Id `com.dincccc.privatetaskbar.taskbarwidget`（含 `taskbarwidget` 标记，宿主自动豁免灵动岛"显示内容"列表）；DisplayName「定制任务栏」；Version 1.0.0；Author `dincccc`。
- 贴**主屏**工作区底部的胶囊悬浮条（高约 52 逻辑像素，宽随内容自适应，圆角），与 Windows 任务栏叠加共存，不改系统设置。
- **默认完全透明**：平时只有白色内容悬浮；**鼠标悬停约 150ms 淡入半透明深色圆角背景 + 细边框**，移出淡出。
- 位置：**默认「贴托盘」（工作区右缘）**；右键菜单三档：开头 / 居中 / 贴托盘；「位置微调」子菜单：左移 10px / 右移 10px / 重置（±10px 步长，累计偏移夹在 ±500px）。位置持久化。

## 2. 内容模型（模型 B）

条内布局（左 → 右）：**媒体控件区 → 监控组**。

### 2.1 有媒体播放时
- **媒体控件区**，内部顺序（左→右）：
  1. 封面（约 36×36，圆角）
  2. 两行文字：**上行 = 歌名 - 歌手**（歌名超宽截断加 `…`）；**下行 = 歌词当前句**（静态、超宽截断加 `…`；「歌词」开关关闭时下行留空，布局不变）
  3. 三个按钮：**上一曲 / 播放暂停 / 下一曲**（矢量图标：⏮ ⏯ ⏭ 自绘，22×22 热区，hover 高亮）
  4. **5 柱迷你频谱**（播放时常显）
- **监控组**（常驻，见 2.3）
- 交互：**点封面或歌名 = 打开正在播放的应用**；左键空白无操作。

### 2.2 无媒体时
- 媒体控件区整块消失（含歌词/频谱/按钮），监控组按勾选显示。
- 若监控项也全部关闭 → 条保留**透明空壳**（固定小宽度，hover 显轮廓），**右键菜单永远可用**（配置入口不丢失）。

### 2.3 监控组（常驻，独立开关）
- 项：时间日期星期 / CPU / RAM / GPU / 网速。
- **出厂默认：只勾「时间日期」**，其余（CPU/RAM/GPU/网速）默认关。
- 时间：24h 制 `HH:mm` 粗体白 + `10月24日`、`星期六` 小字（白 65% 透明度）。
- 占用：`CPU 22%` 式（标签小字 + 数值），GPU 拿不到时显示 `--`。
- 网速：`↑ 3.2MB/s`、`↓ 12.8MB/s` 左右并排，**箭头与文字统一白色**，单位自适应 B/KB/MB/GB（1024 进制，<1KB 取整，其余 1 位小数）。
- 显示值平滑过渡（Lerp）；采样 1 秒。

## 3. 右键菜单（自绘，结构对齐参考图，文案精简）

```
播放 / 暂停          ← 按 MediaController.IsPlaying 动态
上一曲
下一曲
──────────
开头                ○
居中                ○
贴托盘              ●   ← 单选组，当前档打点
位置微调            ▶   子菜单：左移 10px / 右移 10px / 重置
──────────
✓ 媒体控件
✓ 歌词
✓ 时间日期
  CPU
  RAM
  GPU
  网速
──────────
打开正在播放的应用
关闭组件
```

- 「关闭组件」= 会话级隐藏条 + 灵动岛提醒（不再弹长文案）；恢复：插件中心禁用→启用，或重启宿主。
- 设置全部经 `GetSetting/SetSetting` 持久化（除会话级隐藏）。

## 4. 数据采集

| 数据 | 方案 | 说明 |
|---|---|---|
| CPU | `GetSystemTimes` 差值 | 与本体 `Renderer.Media.cs` 同款算法，同源 |
| RAM | `GlobalMemoryStatusEx` | 同上 |
| GPU | 性能计数器 `GPU Engine` Utilization 求和 | 60s 重建实例列表；失败永久降级显示 `--` |
| 网速 | `NetworkInterface` 非环回/非隧道接口收发差值 | 1s 差值 |
| 频谱 | **`new AudioAnalyzer()` 复用本体 public 类** | 与灵动岛同源 5 柱；仅媒体激活时启动实例、无媒体时 Dispose 省资源；`GetBars()` 每帧现读不缓存；宿主升级致不可用时 try/catch 降级隐藏频谱区，其余功能不受影响 |
| 媒体 | `MediaController.Instance`（public 非冻结） | 读短、不缓存位图；缩略图以引用相等为 key 缓存自绘小副本 |

## 5. 技术与工程约束

- net10.0-windows10.0.19041.0 类库，ProjectReference 引用主工程；自带 `NativeMethods`（不依赖宿主 `Win32` 内部结构）。
- 任务栏本体 = 插件专用 UI 线程上的自建 Win32 分层窗口（`WS_EX_LAYERED|TOOLWINDOW|TOPMOST|NOACTIVATE` + DIB + SKSurface + `UpdateLayeredWindow`）；**不用** `host.CreateWindow`（强制居中/固定尺寸/关闭按钮/Esc/无右键，均不适配）。
- 不注册灵动岛 `IWidget`。
- SKPaint 绘制时临时创建、用完释放；宿主字体（`FontConfig.Normal`）现取现用、绝不缓存绝不 Dispose，订阅 `FontConfig.Changed` 重排（try/catch 降级）。
- 后台写/渲染读一律 volatile/lock 保护；动画帧 ~32FPS（`SetTimer` 31ms）。
- 优雅停机：`Dispose` → 窗口线程退出 + `SystemMonitor` 释放 + `AudioAnalyzer` 释放；支持热重载。

## 6. 明确不做（不列入扩展计划）

- 多显示器跟随（只主屏）。
- 开始按钮、运行应用 dock、系统托盘信息。
- 歌词滚动/翻译、GPU 厂商 SDK（NVML 等）。
- 发布到插件市场（Id 已按可发布规范预留，永久不改）。

## 7. 验收清单（真机）

1. 装上即见：底部贴托盘透明条，仅时间日期星期白字；hover 显背景。
2. 播放音乐：媒体区展开（封面+歌名-歌手/歌词+三按钮+5 柱频谱跳动）。
3. 右键：菜单结构=第 3 节；切「显示 CPU」等开关即时生效且重启记住；位置三档+微调±10px 生效。
4. 全关+无媒体：空壳仍在，hover 显轮廓，右键菜单可用。
5. 「关闭组件」：条消失+灵动岛提醒；插件中心禁用→启用恢复。
6. 热重载不崩溃；"显示内容"列表不出现本插件。
